## Official Steam Requirements

These requirements come from the Steam appdetails record for Bodycam, checked on 2026-09-07. Because Bodycam is in Early Access, check the latest Steam listing if you are making a hardware or purchase decision after a major update.

| Requirement | Minimum | Recommended |
|---|---|---|
| OS | Windows 10/11 | Windows 10/11 |
| Processor | AMD Ryzen 7 3700X or Intel Core i7-9700K | AMD Ryzen 7 3800X or Intel Core i7-10700K |
| Memory | 8 GB RAM | 16 GB RAM |
| Graphics | AMD Radeon RX 5700 (8 GB) or NVIDIA GeForce RTX 2070 (8 GB) | AMD Radeon RX 6600 XT (8 GB) or NVIDIA GeForce RTX 3060 (12 GB) |
| Network | Broadband Internet connection | Broadband Internet connection |
| Storage | 50 GB available space | 50 GB available space |
| Additional notes | SSD recommended | SSD recommended |

## How to Read the Table

Minimum means the official listed floor, not a promise that every map, mode, or update scenario will feel smooth at high settings. Recommended gives a better starting point, but it is still not a benchmark chart.

If you are close to minimum, prioritize stable frame pacing and clear visibility over cinematic settings. If you are above recommended but still see uneven performance, use the [best settings guide](/guides/best-settings/) and check current patch notes before assuming your hardware is the only cause.

## Platform Boundary

This project covers the PC / Steam / Windows version. It does not publish console, mobile, VR, or cloud availability claims unless Reissad Studio or Steam provides a current official source.

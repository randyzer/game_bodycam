## What the Tactical Tablet Does

Bodycam's official Steam page describes a world without full-screen menus, with the tactical tablet acting as a command center. It connects loadouts, gadgets, inventory, settings, matchmaking, and the Shooting Range HUB into the game space instead of treating them as a detached lobby screen.

That design changes how players should think about setup. The tablet is not only where you click options; it is part of the rhythm between testing, preparing, and entering matches.

## Use It for Decisions

| Decision | What to check |
|---|---|
| Loadout readiness | Is the weapon/equipment setup appropriate for the mode and map style? |
| Settings sanity | Are display, audio, and input choices still comfortable after the latest update? |
| Practice | Does the build feel stable in the Shooting Range HUB before a real match? |
| Matchmaking | Are you entering a mode that fits your current goal: learning, teamwork, or chaos? |

## v0.8 Input Caveat

The v0.8 #1 patch notes mention a fix for tablet inputs being consumed by gameplay controls. If your tablet behavior feels wrong after changing binds, check controls first, then verify you are on the current build before assuming the tablet itself is broken.

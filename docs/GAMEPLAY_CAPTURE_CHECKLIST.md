# Current-build captures needed for actionable Bodycam guides

The 14 October 2026 source set confirms the PC game, broad Zombies loop and some visual effects. It does not contain a verified current keybind table, settings menu, or Asylum/Village route. These captures are needed before adding fixed instructions or annotated game screenshots.

1. **Build identity:** record the installed game version/date and a screenshot of the title or patch screen that displays it. Note whether the session uses the Steam public build or another branch.
2. **Controls:** capture the full current Controls menu, including any scrolling sections. Record action names, default keyboard/mouse bindings, changed bindings and conflicting-input warnings. Test at least movement, fire/aim, reload, interact and voice in the game before publishing a default table.
3. **Settings:** capture display, graphics, image-effects, audio and input menus. For any recommended setting, record PC hardware, resolution, before/after value, repeatable scene and measured result; otherwise present it only as a test option.
4. **Zombies maps:** for each Asylum/Village claim, capture the start position, visible landmark, each door or switch in route order, map/objective prompt and result after interaction. Record the wave/build and whether the route was repeated in a second run.
5. **Editorial review:** annotate only details visible in the matching capture; cite the official patch if a mechanic changed; avoid teammate names, voice chat, Steam account data and misleading cropped context.

Until these are collected, the public guides provide a build-independent test/checklist and explicitly leave fixed bindings and map point locations open. Do not use competitor screenshots or copy unverified route text as evidence.

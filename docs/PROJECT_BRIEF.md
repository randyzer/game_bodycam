### Derived Direction

- Visual status: DERIVED from first-party official site, Steam media, and official YouTube.
- Primary palette: near-black / charcoal / exposed concrete gray.
- Secondary palette: desaturated olive, night-vision green-gray, muted metal, warning red only as a small accent.
- Environmental lighting: harsh flashlight/weapon light, high contrast interiors, rainy/trench daylight, low-light Zombies spaces.
- Typography character: condensed tactical labels for chrome; readable sans-serif for guide content.
- UI / material language: bodycam overlay, tactical tablet, scanline/recording/noise cues, physical equipment surfaces.
- Map / world language: photoreal CQB interiors, trenches, abandoned facilities, villages, real-world tactical locations.
- Image style: real game footage/screenshot first; no cartoon, fantasy, neon arcade, or generic military clipart.
- Texture / shape language: hard rectangles, camera frame lines, glass/noise, small red recording cues, compact data panels.
- Visual anti-patterns: generic esports gradients, purple-blue SaaS look, soft fantasy cards, Roblox/bodycam-shooter confusion, horror-film Bodycam imagery.
- Iconography: minimal tactical symbols, weapon/settings/map icons only where helpful.
- Available media: official website video/stills, Steam screenshots, Steam store videos, YouTube official trailers/devlogs.
- First-screen composition: literal Bodycam title, Steam/Reissad context, v0.8 update status, strong official gameplay visual or approved embed fallback.
- Light / dark balance: dark-first with restrained high-contrast text; do not make the entire site black walls without content rhythm.
- Saturation: low to medium; accent color should feel like recording/status UI, not decoration.
- Rights-safe fallback if evidence is limited: use embedded official YouTube videos and original diagrams/checklists based on verified facts; do not copy competitor media.
- Visual debt / assumptions needing Human approval: commercial reuse of Steam/official screenshots or local rehosting must be approved before Phase 3.

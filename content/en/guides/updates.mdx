For current Bodycam changes, use the [official Steam news feed](https://steamcommunity.com/app/2406770/allnews/) or the game's [Steam Community announcements](https://steamcommunity.com/app/2406770/). This page is a dated reading aid, not a live changelog.

## v0.8 announcement

Reissad Studio's [Locked & Loaded announcement](https://store.steampowered.com/news/app/2406770/view/674001920444073955) set 2 September 2026 as the planned release date for v0.8. The developer described a broad technical and gameplay overhaul, with devlogs for loadouts, sound, Trenches and player-driven improvements. See our <GuideLink slug="guides/locked-and-loaded">update overview</GuideLink> for the scope and its limits.

## What patch #6 actually says

The [25 September 2026 patch #6 note](https://steamcommunity.com/games/2406770/announcements/detail/705532193278002608) records fixes for player limits after host migration, especially in Wingman; several reload, swap and ammunition-display issues; a Film Grain setting issue; and server-browser refresh consistency. These are version-specific fixes, not proof that no similar bug can return.

The same developer note says the new party system was **not ready yet** as of that date. It describes a plan for an experimental branch before general release. We cannot turn that plan into current step-by-step friend invitation instructions without a later official confirmation.

## Reading future changes

Check each announcement's date and version before acting on it. A planned feature, a live patch and a developer work-in-progress note mean different things. For a question about today's behavior, a newer official note or the current client is more useful than an older guide.

**Quick answer:** use the tactical tablet in the Shooting Range HUB to reach settings, check the actions below, then test any changes at the range before matchmaking. The [official Steam description](https://store.steampowered.com/app/2406770/Bodycam/) confirms the tablet and range. It does not publish a complete default key list, so use the bindings displayed by your installed build.

## Five-minute binding check

1. In the Shooting Range HUB, follow the in-game prompt to open the tactical tablet, then open settings and find the input or keybinding section. Record the displayed bindings before editing anything; the tablet's exact opening key has not been verified for this guide.
2. Check the actions you need to move, look, fire, aim, reload and interact. Inspect character and perk bindings separately if your menu shows both groups.
3. If a binding feels awkward, change **one** action. Make sure it does not conflict with another action you use in the same mode.
4. Practice the action at the range before joining a match. If it fails or creates a conflict, restore the recorded default.
5. If a customized key stopped working after an update, check the binding again. [Patch v0.8 #4](https://steamcommunity.com/games/2406770/announcements/detail/713412222387225083) reworked conflict handling, split perk and character inputs, cleared outdated saved binding data and warned that some modified keys may need to be rebound.

If you are changing mouse sensitivity, keep a repeatable reference: stand at the same spot, turn toward the same landmark, and adjust one step at a time. A setting that helps someone else's mouse and desk space may not help yours.
